## 👨‍💻 About Me

I'm **Tanuj Verma**, a Full Stack Developer based in **Delhi NCR, India**, currently working at **Performdigi Monetize**.
I'm early in my career and have hands-on experience delivering practical client projects end to end.
On the frontend I work with React.js, Next.js and TypeScript; on the backend with Node.js, Express.js and PHP (CodeIgniter), backed by MySQL and MongoDB.
I enjoy building clean, responsive interfaces and the REST APIs that power them.
